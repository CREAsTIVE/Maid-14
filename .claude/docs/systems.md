# Systems index

Index of content systems. Each documented system has its own file in `systems/`; systems without a file are not documented yet. Engine-level mechanics are in `ecs.md` and `ecs/`.

## Documented
- Interaction and ActionBlocker: `systems/interaction.md`
- Hands and Inventory: `systems/hands-inventory.md`
- DoAfter: `systems/doafter.md`
- Damage: `systems/damage.md`
- Mob state: `systems/mob-state.md`

## Not documented yet
Verbs, Item and ItemSlots, Storage, Tools, Whitelist and Tag, Status effects, Popups and Examine, User interfaces, Power, Doors, Movement, Combat, Actions, Alerts, Access, Atmos, Chemistry, Body (Shitmed), Construction, Wires, Stack, Chat and Radio, GameTicking, Station and Jobs, Cargo and Economy, and Maid-owned systems (in `_Maid` folders).
