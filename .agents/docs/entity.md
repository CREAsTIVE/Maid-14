# Entities

Entities are covered together with components in `ECS.md`, since neither is meaningful without the other: an entity is only an identifier, and everything it is and does comes from the components attached to it.

See the **Entities** section of `ECS.md` for identity and references, creation from prototypes, lifecycle, the world hierarchy (maps, grids, parenting, containers), categories, and deletion. The **Components** section there covers data, networking, composition and prototypes. Behavior is described in `systems.md`.
